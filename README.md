# Дохионы Telegram бот

buy-sell.html хуудастай ижил дүрмээр 30 минут тутам дохио шалгаж, шинэ BUY эсвэл SELL гармагц Telegram руу оролт, SL, TP-тэй мессеж илгээнэ. Компьютер унтарсан ч GitHub дээр өөрөө ажиллана. Үнэгүй.

## 1. Telegram бот үүсгэх (2 минут)

1. Telegram дээр **@BotFather** гэж хайж нээгээд `/newbot` гэж бичнэ.
2. Ботын нэр (жишээ нь `Миний дохио`), дараа нь `bot`-оор төгссөн хэрэглэгчийн нэр (жишээ нь `minii_dohio_bot`) өгнө.
3. BotFather өгсөн **токеныг** хуулж аваарай (`123456789:AA...` хэлбэртэй). Энэ бол нууц үг, хэнд ч бүү өг.
4. Шинэ ботоо нээгээд **Start** дарна. Бот таны чатыг ингэж танина.

## 2. GitHub репо үүсгэх

1. github.com дээр бүртгүүлж нэвтэрнэ.
2. Баруун дээд **+** → **New repository**.
3. Нэр: `signal-bot`. **Private** сонгоно. **Create repository** дарна.
4. Нээгдсэн хуудсан дээрх **uploading an existing file** холбоосыг дарна.
5. Энэ zip-ийг задлаад доторх **бүх файл, хавтсыг** (`.github` хавтас орно) хуудас руу чирж оруулна. **Commit changes** дарна.
   - `.github/workflows/signals.yml` файл орсон эсэхийг шалгаарай. Ороогүй бол **Add file → Create new file** дарж, нэрэнд нь `.github/workflows/signals.yml` гэж бичээд агуулгыг нь хуулж тавина.

## 3. Нууц түлхүүрүүдээ оруулах

Репо дотор **Settings → Secrets and variables → Actions → New repository secret**:

| Name | Secret |
|---|---|
| `TELEGRAM_TOKEN` | BotFather өгсөн токен |
| `TWELVEDATA_KEY` | Twelve Data-ийн түлхүүр |

## 4. Эхлүүлэх

1. Репогийн **Actions** таб → **Дохио шалгах** → **Run workflow** дарна.
2. 1 минутын дотор Telegram-д **"✅ Дохионы бот ажиллаж эхэллээ"** гэж ирнэ.
3. Цаашид 30 минут тутам өөрөө шалгана.

## Хослол солих

`config.json` файлыг GitHub дээр нээгээд харандааны дүрс дарж засна. Жишээ нь алтыг 4 цагаар нэмэх бол:

```json
{ "pair": "XAUUSD", "tf": "4h" }
```

Хослол: `XAUUSD`, `EURUSD`, `USDJPY`, `AUDUSD`, `AUDCAD`, `CADJPY`, `ETHUSD`
Хугацаа: `30m`, `1h`, `4h`, `1d`

## Анхаарах

- GitHub-ийн хуваарьт ажил заримдаа 5–20 минут хоцордог. Тиймээс мессеж лаа хаагдсанаас хойш хэдэн минутын дараа ирж болно. Дохио "шинэ" хэвээр байгаа үед л илгээнэ.
- Private репод GitHub сард 2000 минут үнэгүй өгдөг. Энэ бот сард ойролцоогоор 1500 минут зарцуулна.
- Репод 60 хоног ямар ч өөрчлөлт ороогүй бол GitHub хуваарьт ажлыг зогсоодог. Бот илгээсэн дохиогоо `state.json`-д тэмдэглэх бүрдээ өөрчлөлт хийдэг ч, удаан дохиогүй байвал Actions таб дээр "Enable workflow" гэж гарч магадгүй.
- Энэ бол автомат техник дохио, санхүүгийн зөвлөгөө биш.
